# Addendum: tool-evidence retrieval and report fidelity

This retrospective development analysis evaluates acquisition, identity/version binding, traceable delivery and qualification of existing computational evidence. It does not measure biological knockdown efficacy, off-target safety, general scientific reasoning, autonomous planning quality, or human effort saved.

The original mini-model batch contains nine previously seen task templates in three configurations, 27 answer positions and 33 user rounds. W1/W2/W2b/W3 are four standard tasks, U1 is one requirement-change task, and R1–R4 are four reliability tasks. Each configuration was run once per template; rounds and required slots are not independent tasks or biological replicates. The raw answers, internal model text, attachments, failures and original ordinal expert ratings were preserved. Neither the original batch nor the earlier failed 54-position development batch was rerun.

The ordinary model had no scientific tools. The fixed workflow received prepared structured conditions; the Agent used the same base mini model as the ordinary-model arm and could plan/use tools. Both tool configurations accessed the same prepared scientific assets. These conditions do not measure end-to-end input-preparation labor. Original costs remain 11 model requests/59,828 tokens for the ordinary model and 51 requests/445,436 tokens for the Agent; the workflow made no model requests. Zero model requests does not imply zero total computational or human preparation cost. No monetary cost or labor reduction is inferred.

Main scoring scope is each delivered final answer plus explicitly delivered, accessible business/data attachments. Internal model drafts, raw requests/responses and logs are diagnostic and do not substitute for delivery. A013 contains a documented software false block despite correct internal core/context strings; accessible attachment fields and the contradictory main display are separate observations. A011 and A025 share an error-presentation template, although A025 had six model requests and A011 had none. Template/validation contributions belong to the system, not uniquely to autonomous model reasoning.

Existing AI provisional judgments cover 135 required slots in each configuration (405 judgments). CORRECT contributes TP; WRONG contributes FP and FN; MISSING contributes FN. Undefined/unknown judgments are not imputed as zero. Task pass/fail is distinct from slot extraction. No finite negative universe exists for C1 planning accuracy; strict planning metrics remain unavailable. Micro measures aggregate slots; macro measures average per-task measures. Standard tasks, reliability tasks and the single change case remain separately tabulated. Original ordinal 0–2 ratings were not converted into binary labels or pooled across unconfirmed rater relationships.

Recalculation of the saved AI labels yields task passes of 1/9, 8/9 and 6/9 for ordinary model, workflow and Agent, respectively. Required-slot micro precision/recall/F1 are 0.820896/0.407407/0.544554, 1/0.962963/0.981132 and 0.992248/0.948148/0.969697. Macro F1 is 0.597789, 0.949495 and 0.953704. These are AI-preliminary retrospective descriptions, not independently approved human ground truth or evidence of general Agent superiority. The concurrent audit at ab54de1 corrected stale summary values without changing the original labels; this execution independently checked the same labels and preserved both versions.

Independent code-path validation used the archived 19,415 representative 3′UTRs, their transcript-to-gene manifest and the actual guide inputs of each official task. The default nine used the archived full guide input; the purchased case used the official task's explicit core input. The mer7m8 target motif is the reverse complement of guide positions 2–8, converted to DNA. Literal, overlapping matches were scanned on forward transcript sequences, with N treated as a literal nonmatching base. Per-site coordinates, transcript counts and gene counts agreed exactly for all ten guides with the archived official output. This verifies a defined exact counting operation and input binding, not experimentally observed off-target effects.

Expression detection was independently recalculated from eight original company TPM columns: four normoxia and four hypoxia dishes from one culture run, not paired independent experiments. TPM ≥1 in at least two of four dishes defines the existing descriptive detection rule. The shared static feature-to-Entrez map is disclosed; only its identifiers were used as calculation inputs, not its saved TPM/detection columns. All ten guide-associated mapped/unmapped and state-detected gene sets, as well as gene-level replicate counts, matched the packaged comparison data under the same mapping version. The purchased guide matched 2,836 mapped, three unmapped, 1,695 normoxia-detected and 1,595 hypoxia-detected nontarget genes.

An initial run with a different reference-locus mapping produced 35 candidate-by-gene discrepancies and 100 set-membership differences. That run and every difference were retained. The subsequent same-version comparison resolved this mapping-scope mismatch without changing thresholds or historical outputs. Annotation-version sensitivity is a limitation; neither mapping is established here as independent biological truth.

Arithmetic checks were conditional on shared candidate, reference, version, units and filtering: all sites = nontarget sites + target sites; matched genes = mapped + unmapped; each detected-state set is bounded by mapped genes. Normoxia and hypoxia may overlap. Missing fields were UNCHECKABLE and were not filled from reference tables. Such consistency is necessary but cannot establish external validity.

New software changes and saved-answer/synthetic controls are separate artifacts. No new paid model requests, human ratings, prediction training, ranking weights, wet-lab work, deployment or browser acceptance occurred. OligoFormer prediction was not independently rerun; source-row fidelity is distinct from prediction calibration. Independent human confirmation, comparable original planning artifacts, unseen-task evidence and biological efficacy/safety measurements remain unavailable.

Do not relabel dimensions as Accuracy/Precision/Recall/F1 or user-experience outcomes. No new comparative figure is generated from unapproved AI labels.
