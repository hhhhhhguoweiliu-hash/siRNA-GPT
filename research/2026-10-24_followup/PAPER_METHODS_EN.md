# Draft Methods: historical fixed candidate pool and evidence library

This wording describes verified historical records. It does not report a new design run, new heavy-model inference, a new biological experiment, or a validated optimal selection rule. The later 12:49 review supersedes the earlier tentative experimental shortlist.

## Candidate origin and historical working selection

The complete 3,609-nt human VEGFA reference transcript NM_003376.6 was submitted to siDirect 2.0. The retained request, reference sequence and original HTML response were cross-checked in a separate provenance audit. The original response contained 104 designs. The recorded request enabled the Ui-Tei rule and a seed-duplex melting-temperature filter with an upper setting of 21.5 degrees C, selected the human reference option, and used the full input sequence. The request did not enable the near-full-length mismatch/hide option, so that criterion was applied downstream. Values recorded in text fields, including consecutive-base limits, a custom pattern and a 0-100% GC range, were not interpreted as enabled server filters when their corresponding switches were absent. The exact historical server database release was not recoverable. One original design printed a guide temperature of 21.5 degrees C at one-decimal precision; this rounded boundary was retained rather than retrospectively excluded.

The recovered project script retained designs with a recorded minimum mismatch count of at least two for both strands, paired-core GC content of 30-65%, no run of four or more identical bases in either paired core, and exact paired-core matches to all 20 fixed VEGFA reference transcripts. Applying these conditions sequentially left 104, 65, 20, 12 and 9 designs, respectively. Individual exclusion counts overlap and must not be summed. The reference accession list was determined using the vendor transcript annotation, whereas reference sequences were obtained from NCBI. Baseline expression values did not generate this list. These additional GC, homopolymer and all-transcript conditions were historical project working choices, without independent validation of optimality. In particular, a poly-A/T termination rationale for polymerase-III-driven short hairpin RNA was not assumed to validate the same exclusion for chemically synthesized siRNA. Matching all 20 references was a design goal rather than a general efficacy or safety requirement.

All nine retained designs were preserved as a fixed computational development pool. The guide 21-nt sequence is the reverse complement of the first 21 bases of the 23-nt sense design window; the passenger 21-nt sequence corresponds to window positions 3-23 in RNA alphabet. The paired 19-nt core occupies sense-window positions 3-21. Coordinates are one-based and inclusive; for example, VEGFA_SD_3499 has design-window coordinates 3499-3521 and paired-core coordinates 3501-3519. Original terminal bases were retained. On NM_003376.6, whose annotated coding sequence spans 497-1684, the 1157 design core lies in the coding sequence and the other eight cores lie in the 3prime untranslated region. Reference matching does not establish that every target region is present in the transcripts expressed in the experimental cells. The designs are not a finalized synthesis order.

## Historical prediction and sequence annotation

Previously saved OligoFormer outputs were used as annotations after candidate selection. The historical CPU adapter called the official model at commit e2f53ad63387bbe166bf123949151e2bc9bf6ec3 with its original weights, RNA-FM features, a 19-nt paired core and 57-nt mRNA context. The adapter explicitly used inference mode and disabled gradients; this recorded CPU adaptation was distinguished from reproducing the complete upstream Unix command-line workflow. The saved class-1 output was multiplied by the official factor 1.341. This value is a model score, not a measured knockdown percentage or a calibrated probability. The original palindrome-check flag func_filter=4 was retained for designs 3119, 3193 and 3502; the separate historical near-full-length review flag for 3535 was also retained. No PITA, TargetScan, toxicity or mismatch-model validation is claimed here.

Historical SeedMatchR 1.1.1 outputs were generated by sourcing its two unmodified official core-function files, rather than installing the complete package. The reference comprised one representative annotated 3prime UTR per gene for 19,415 genes, based on GRCh38.p14/RefSeq RS_2025_08. Representative UTR selection preferred NM accessions, the longest UTR and then accession order; it did not identify experimentally dominant ARPE-19 isoforms. The historical calculation included both strands and four seed types, with no mismatches or indels; all 1,397,880 count rows were retained in the provenance materials. The current application uses the explicitly defined guide mer7m8 positive-count subset, corresponding to guide positions 2-8. Site counts, distinct matched genes, genes mappable to the baseline expression table and genes detected in each state were reported separately. Seed matches indicate possible sequence interactions and do not establish off-target gene suppression or toxicity.

The ARPE-19 baseline comprised four culture vessels per state from one culture run, with hypoxia specified as 1% oxygen for 24 h. These samples were not siRNA-treated measurements and were not described as four independent culture runs. Expression was used only as background annotation and did not enter candidate scores or a state-related risk reranking. No wet-laboratory knockdown values are available for these nine designs. Full historical shell invocations, per-process exit codes and the precise siDirect server database version remain unavailable; recovered scripts, input/output files, version records and successful/failed logs are supplied separately.

## Small source-grounded literature component

The library retained the original tool papers, official documentation/source files and clearly labelled project records, and added only three specified experimental articles: Chen et al. (2013), DOI 10.2147/IJN.S39622; Osipova et al. (2020), DOI 10.3390/pharmaceutics12010039; and Kleinman et al. (2008), DOI 10.1038/nature06765. The first two were acquired as full article XML from PMC and extracted into text with stable XML-block locators. The third was acquired as a 15-page institutional author manuscript, with actual PDF page locators; its supplementary sequence table was not included. Originals, hashes, source declarations, acquisition records and extraction coverage were retained. Document count is not the number of independent papers: the expanded library contains 12 materials, representing six distinct papers plus documentation and local records, with a duplicate-format siDirect paper.

Chinese query terms were expanded through an explicit small bilingual lexicon and searched using SQLite FTS5. No model fine-tuning or vector service was introduced. Project-setting cards, published findings and local calculation records remained distinct. Returned excerpts and locators were passed in the actual question request. A scope stop before retrieval was recorded separately from an executed search returning no results. Related text was not treated as proof of an unreported candidate-, cell- and time-specific measurement. Offline checks and the targeted single-question regression are development verification only, not an unbiased accuracy estimate or evidence of superiority over the historical comparison groups. No independent human quality scores were assigned by the developers.
