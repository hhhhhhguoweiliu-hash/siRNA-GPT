# Actual execution scope for the manuscript

After explicit user authorization, we executed nine previously seen development templates with three configurations once each (27 scheduled units and 33 user-round units). The configurations were a language model without scientific tools, a deterministic tool workflow, and a tool-using Agent. The two language-model configurations used doubao-seed-2-0-mini-260428 through the Volcengine Ark Responses API, with thinking disabled, a maximum of 1,800 output tokens per response, a 720-second case limit and a 360-second round limit. The fixed workflow made no language-model calls. Common original inputs, round-specific requests and scientific resource versions were checked against the recorded protocol. The workflow used predefined routing; the Agent could make multiple planning and execution calls, so resource use was not equal across configurations.

All 27 scheduled units were attempted. The development batch contained 62 actual model requests and 505,264 provider-reported tokens, with no HTTP retries. A separate connection and tool-return check used two requests and 605 tokens and was excluded from the 27 units. An earlier diagnostic using doubao-seed-2-1-pro-260915 returned HTTP 403 (AccessDenied); its original failure was retained and its unavailable usage was not treated as zero. No full batch was executed with that earlier model.

Raw requests, responses, tool evidence, partial outputs and stops were retained for every scheduled unit. Three execution stops were retained: two cases lacked the required user expression table and prohibited substitution of the built-in table; one supplied a changed guide core that was not complementary to the unchanged passenger core. Software statuses, provider response completion and tool-call counts were not used as scientific quality labels. No human scores, success rates or superiority claims were generated. Reference criteria and anonymous deliveries were provided separately from execution inputs, with the configuration keys withheld from reviewer material. Writing style and recorded processes may nevertheless reveal configurations, limiting blinding.

The five primary work or requirement-change templates and four reliability templates must be reported separately. Some templates share a candidate; these are seen development cases rather than independently authored unseen tests or independent biological replicates. Human scientific scores remain blank; comparative quality statistics await independent review and resolution of disagreements. Existing computational outputs were imported with sequence and reference bindings; this batch did not rerun OligoFormer, SeedMatchR or near-full-length scans, measure knockdown, or assess the physical N3-linked construct.
