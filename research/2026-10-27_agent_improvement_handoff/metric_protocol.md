# 四项指标怎么算，当前需要补什么

日期：2026-10-27。基点提交 `3f692e0b252cb4ffc46ba3881defb998d2c3af98`。此文件是建议的可复核标注方案，尚未由独立真人确认，未产生新分数。任务范围与实现要求见[交接复核](../../docs/reviews/20261027_agent_improvement_and_metric_handoff.md)。

## 1．先分清评价对象

CRISPR-GPT Figure 3b / Supplementary Note C1（PDF索引27，即第28页）比较“生成的子任务列表”与“专家标准子任务列表”。它不是把四个专家量表维度改名成四个分类指标。原文也另外定义整份回答正确数/请求数的Accuracy，二者单位不同，不能混用。

本项目当前有：
- 当前九个已见开发任务、三组共27份真实答复；U1/R1的两轮各合为一个任务单元。
- 原始输入、工具证据、附件和0–2四维专家评分。
- 必答要点草案，缺确认的原子标准与当前27份答复的逐项标注。
- 现有普通模型没有与两工具组对等的结构化计划输出。

因此建议先补现有答复内容评价；严格的C1规划评价仍列缺口。

## 2．标准二分类/步骤选择的四项公式

必须先确定每题有限的步骤集合，以及各步骤“应选/不应选”的专家标准；同一集合、同一标准用于所有组：

| 专家标准 | 系统实际选择 | 计数 |
|---|---|---|
| 应选 | 选了 | TP（选对） |
| 不应选 | 选了 | FP（多选/错选） |
| 应选 | 没选 | FN（漏选） |
| 不应选 | 没选 | TN（正确不选） |

- Accuracy = (TP + TN) / (TP + FP + FN + TN)
- Precision = TP / (TP + FP)
- Recall = TP / (TP + FN)
- F1 = 2TP / (2TP + FP + FN)，等价于2PR/(P+R)。

计划选择、实际执行、最终回答正确性是三个对象，不能混作同一张计数表。次序/参数是否正确需单独核对，集合指标高不等于完整任务正确。允许的替代路径、可选步骤和依赖应提前说明；可选项不能简单当错误多选。需要澄清或停止的情形按实际轮次/条件评，不强迫执行无效计算。

TN不能从无限的“所有没说的错误内容”中凑数；也不能为某组增加容易的负例。没有明确全集时，TN和该定义的Accuracy留空。若只标必答项目且全部为正例，硬算的Accuracy会退化为Recall，不应制造四个看似独立的指标。

仅作公式演示：TP=8、FP=2、FN=4、TN=6时，Accuracy=70%，Precision=80%，Recall=66.67%，F1=72.73%。这是假设例子，不是本项目结果。

C1完整数据最少是每题/轮次/步骤的 `gold_selected`、`predicted_selected`、标准批准记录、计划原文定位和版本。当前不能把普通模型的 `predicted_selected` 自动填0：没有记录不是明确没选。缺对等原始计划时保持空值与 `NOT_READY`。

## 3．现有27份答复可以补的内容评价（建议先做）

为节省时间，复用原答与证据，无需新模型调用。建议报告两种粒度，图注写明，不冒充C1：

### 3.1 必答要点Precision / Recall / F1

将要求拆为可核验的独立槽位，例如“SD_3499的scaled分数”与“分数是否代表实测敲低率”是两个槽位。先确认每槽可接受的值/说法、容差及来源，再读三组答复：

| 槽位状态 | 定义 | 计数 |
|---|---|---|
| CORRECT | 一致、准确地交付了该槽位的可接受答案 | TP+1 |
| WRONG | 提供了错误或自相矛盾的值/结论 | FP+1，同时FN+1 |
| MISSING | 未交付所要求的值/结论；如只说“模型分数”，未给要求的数值 | FN+1 |
| UNJUDGED | 尚未判定、证据不足或需裁决 | 不得自动变0或MISSING；阻止正式汇总 |
| NOT_APPLICABLE | 经批准该槽位不适用 | 同题所有组按相同规则处理，并说明原因 |

错误值同时FP与FN的原因是：多了一个错误答案，同时所需正确答案未被交付。这是“槽位—值”的提取计数，不是生物学分类。每槽只计一次；重复正确说法不加分，同槽多个冲突值不能取其中正确的一个就算CORRECT。

这里的Precision准确名称是“必答要点精确率”：只在预先确定的必答槽位内评价，不代表整篇文字的所有事实都正确。正确的可选补充不增加TP；额外错误/虚构主张需另记，并按已确定的严重程度影响整题通过，不能借此隐藏错误。若要另外评价整篇事实主张精确率，则需完整主张清单与另一套一致分母，不能与本槽位Recall混合计算F1。

例子（假设，不是项目结果）：要求5个槽位，答对3个、答错1个、漏1个，则TP=3、FP=1、FN=2；Precision=75%，Recall=60%，F1=66.67%。该任务不能判严格完整正确。

### 3.2 Task accuracy（整题正确率；也可标Task success rate）

Task accuracy = 达到事先明确通过条件的任务数 / 纳入评价的任务总数。

对旧批应明确为“回顾性制定/确认的标准”，不能宣称是运行前已有人批准。建议通过条件为：本题必须项均正确交付、禁止事项未发生、必要证据可定位、无使结论失效的错误；澄清/部分交付/停止是否构成正确完成按本题要求决定。正确停止不自动等于整题都完成，也不能统一扣为失败。没有敲低实验真值时，不评哪个候选“生物学最佳”。

此指标是整题层面的比例，不是上节由TN参与计算的步骤选择Accuracy。若四根柱同时画，必须标“Task accuracy / Required-slot precision / Required-slot recall / Required-slot F1”，图注说明第一项单位是整题，其余是必答槽位。更清楚的版式是将整题正确率与槽位三指标分面展示。不写成完全复现CRISPR-GPT Figure 3b。

## 4．需要补的表与人工工作

1. `required_slots.csv`：题号、轮次、原子槽位、标准值/合理答案、容差、参考版本/链角色/条件、证据出处、必需或可选、判断标准版本与真人批准记录。
2. `slot_reviews.csv`：每份真实答复逐槽原句/附件位置、提供值、CORRECT/WRONG/MISSING/UNJUDGED/NOT_APPLICABLE、理由、真人确认、自动检查（另列）、裁决。
3. `task_reviews.csv`：任务通过标准、严重错误/禁止事项、PASS/FAIL/UNJUDGED、评审与裁决记录；不得直接把旧“部分完成”算通过。
4. `planning_decisions.csv`：仅当严格C1数据具备时使用。有限步骤全集、应选标记、实际计划选择、计划原句、可用性和批准记录。不要用事后LLM为原模型补写计划。

Codex可提取原文、整理可检查字段、生成空表与机器检查候选；科学上可接受的标准、解释性判断及正式标签须由真人确认。已确认的机器可精确比对字段可自动核对，但必须与真人确认分开存。不能让本对话或Codex代填“专家已确认”。

现有草案59条对应177个三组待检查位置；复合条目拆分后重新计数。原59条仍无运行前人工确认记录，保留这一事实；不要把新批准日期倒填成旧日期。实际匿名编号以当前A001–A027及原运行映射为准，旧33个D编号不可直接套用。评审材料与组别映射分开；已知组别者不改称此前盲评。

## 5．统计、缺失与公平性约定

- 先确认标准，再完成全部三组逐项判定；按题配对，不随哪组分数高改变槽位/规则。
- 旧任务是开发材料，新评价为补充回顾分析。新版本必须另存，修复后的输出不能替换旧27份答复参与原图。
- 标准4题、可靠性4题、需求变化1题分别展示；文献问答未在本27份中实际运行，不拼入本批。
- 每题先算P/R/F1，再分别对同类独立题取算术平均（macro）；macro F1是每题F1的均值，不是先平均P/R再求F1。总TP/FP/FN的micro值可附录报告，避免多候选题独占权重。
- 所有必答槽位已判定且标准已批准后，空答复对应TP=0、FP=0、FN>0；Precision分母0按事先约定显示0并保留 `undefined=true` 和原分母，Recall/F1为0。这条数值约定不适用于待判定/缺标准/缺原件；后者指标为空。无必答槽位的任务不适用本槽位指标。
- 必答槽位/两轮记录不是独立题，27是答复数，不能当每组n=27；当前每组9个已见任务。U1只有1题，不展示伪标准误或显著性。
- 正文、可访问附件与未实际交付的原始模型文字分开。预先声明统一交付评价范围；机器误拦截可作为软件缺陷单独分析，不能事后只取内部正确文本替换用户实际收到的结果。服务/账号失败的处理单列，缺用量不填0。
- 0–2原专家评分不能作为TP/FP/FN/TN输入。评级原表、补充标注与修订记录均保留，不因已知组别或结果改分。
- 同模型/生成设置适用于LLM与Agent；两工具组共享科学工具和可用资料。人工设置布尔条件的成本不算Agent或workflow自行完成；真实人力需另测。
- “提高”先报百分点：80%对60%为+20个百分点；相对提高为(80−60)/60=33.33%。基线为0时相对百分比不定义。负差和持平照实报告。
- 不根据9个已见模板声称泛化或生物学效力；多次技术重复不增加独立样本量。未确认标注时仅交空表/脚本，不画四指标结论。
