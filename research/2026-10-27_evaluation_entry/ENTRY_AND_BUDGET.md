# 现有入口接入与待运行方案

本轮没有授权付费探测或批次，因此没有点击运行、配置账号或部署。新代码沿用原站登录、同源请求和用量确认；启动/部署时不会自动运行评价。旧54记录入口保留，旧结果不改。

## 新入口实际支持

原评价面板可选择新的 `dialogue-v3` 开发集或旧六题集。选择变化会取消用量勾选；新入口先展示当前方案和预算，点击启动时要求该方案指纹与实际设置一致，过期就拒绝。接口预览只读文件和设置，不调用模型。普通模型无科学工具/外网，固定流程按共同条件选预定路径，Agent可规划并多轮调用相同工具；每轮各自重新核对工具，保留自己的对话历史。

单题诊断为W2b普通模型的一次请求，仅验证模型服务记录，不做三组评分。完整开发方案在运行前明确为9个已见W/U/R模板×3配置×1次=27计划单元、33用户轮次；Q1/Q2事前单列，旧33位置开发包原件仍保留。没有把技术重复或同母题变体说成独立题目。

| 默认设置/上限 | 数值与含义 |
|---|---|
| 共同模型 | 实际网页配置的同一模型/接口；此目录方案文件来自无密钥示例配置，不是线上验证 |
| 每请求输出上限 | 1800词元；不等于实际使用量 |
| 每请求超时 | 最多90秒，并缩短到剩余轮/题时间 |
| 每轮/题时限 | 360/720秒；已在共享路径执行并记录 |
| HTTP重试 | 最多1次，只重试既有暂时HTTP错误；账号阻断/超时/截断不自动重试 |
| 普通模型 | 11个用户轮次，最多11次逻辑模型请求 |
| Agent | 11个用户轮次，每轮最多13次含规划；最多143次逻辑请求 |
| 固定流程 | 不调用模型，工具按预选路径运行 |
| 完整计划模型请求上限 | 154次逻辑请求；连同配置重试最多308次HTTP尝试 |
| 输出参数上限的合计 | 逻辑请求277200词元；若每个HTTP尝试都计参数上限则554400。均非账单或费用估算 |
| 输入词元/货币费用 | 尚未知，不假填0、不套未核实价格 |

这是上限，不是预期用量或实际模型预算已验收。实际输入长度随工具返回变化，货币费用未计算；真实响应缺模型版本或用量就保留未知。当前仍需用户以后按原手动入口确认，不自动开始。

## 实际记录与停止规则

每个模型逻辑调用保存准备的输入、接口实际请求体、每次HTTP尝试/时间/超时/重试/错误和请求ID、原始响应、归一化响应、实际返回模型及用量。规划和执行都经过同一记录器。错误或不完整响应留原内容和结束原因；不补猜用量。每次物理响应只计一次，原始/转换后的响应不重复累加；错误返回若有用量也保留，未完整时总量留空并列已知小计。

首次执行失败后该题后续用户轮统一未执行。账号阻断、超时或用户停止会停止批次；其他失败按原计划保留而非重跑消错。所有27位置始终有实际状态，未开始不是失败评分。固定/Agent的工具差异、共享序列检查和用户实际交付与模型原文分别保存，不索取或导出隐藏思维链。

## 正式包生成与目前限制

真实记录生成 `for_review` 及独立评审ZIP：完整问题和输入、逐题标准、原答全文、原始模型文字字段、各轮实际步骤、实际取得的工具证据和附件。参考底表另放，不给没取得证据的答复事后补答。组别密钥和HTTP/提示词完整原件只在执行端完整包。匿名附件副本只移除明确组别元数据/报告标题身份，科学内容不改；记录原件与副本指纹及变化。过程、文风仍可能暴露来源，不保证完全盲法。

服务器不另装电子表格生成库。运行后执行端下载完整包，并执行：

```powershell
python scripts/prepare_runtime_review_workbook.py --run <解压后的本批目录> --output <本批新输出目录>/review_form_blank.xlsx
node scripts/build_review_workbooks.mjs <同一输出目录>/workbook_authoring.json
python scripts/prepare_runtime_review_workbook.py --run <解压后的本批目录> --output <同一输出目录>/review_form_blank.xlsx --verify
```

用官方表格工具生成XLSX后，最后一步实际读回，逐一核对答复ID和所有事实行、确保人工字段全空，另存含XLSX的评审ZIP；不覆盖原运行包。本轮已用明确模拟响应的完整27位置记录走通该导出/读回路径，没有真人分。旧33位置表不当成新27位置表。

仍未支持独立未见题的安全导入、Q1/Q2资源对等、原站新代码部署与实际HTTP验收。没有独立任务时只能报告开发结果；新入口本地接通不能说新三组真实评价完成。
