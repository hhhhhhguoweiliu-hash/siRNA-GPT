# Figure legends

**Fig1. Task-averaged required-slot precision, recall and F1.** Each configuration was evaluated on the same nine seen development tasks. Required-slot metrics were calculated for each task and then averaged with equal task weights (macro averaging). The 405 final slot judgments comprise 312 correct, 12 wrong and 81 missing judgments. They originate from an AI-assisted review with selective user-relayed adjudication of nine disputed judgments, not independent human annotation of every slot. For slot-value extraction, a correct value contributes one TP, a wrong value contributes one FP and one FN, and a missing value contributes one FN. Macro F1 is the mean of task-specific F1 values, not the F1 calculated from mean precision and recall. No error bars, independent repeats or significance tests are implied.

**Fig2. Task-level PASS rate under the existing project-recorded adjudication.** Bars show the number of tasks adjudicated PASS divided by nine tasks per configuration. The 27 task labels and recorded dispute decisions were reconciled to the identical original answer records, verified by their SHA-256. The rates are 0/9 for Generic LLM, 8/9 for Fixed workflow and 9/9 for Agent. This retrospective task-level measure is distinct from conventional binary classification accuracy and does not imply that every detail in a passing response is correct. Recorded non-fatal defects and shared-template attribution limits remain in the evidence tables. These task labels were not inferred from ordinal expert ratings or from the updated slot counts.

**Fig3. Task-level PASS and required-slot metrics evaluated at separate granularities.** Panel a reproduces the existing project-recorded task adjudication summarized in Fig2. Panel b reports the current AI-assisted and selectively adjudicated slot review using micro averaging across 135 required slots per configuration. The panels intentionally preserve different evaluation units and label sources. Task PASS rates are not recomputed from the slot-level confusion counts. The data describe seen development tasks and do not establish unseen-task generalization or biological efficacy.

**FigS1. Overall required-slot precision, recall and F1.** Counts were pooled over 135 required slots per configuration before calculating metrics (micro averaging). Generic LLM has C/W/M = 52/10/73; Fixed workflow has 129/0/6; Agent has 131/2/2. Precision = C/(C+W), recall = C/(C+W+M), and F1 = 2C/(2C+2W+M). These are required-slot/value metrics, not whole-response factual precision or biological performance measures.

**Visual style.** All text uses verified Arial Bold. Muted mauve, blue and mint were sampled from the solid bar fills in Figure 3b of Qu et al., *CRISPR-GPT for agentic automation of gene-editing experiments*, DOI 10.1038/s41551-025-01463-z. The palette is reused for visual consistency only; this project's configurations and evaluation are not claimed to replicate the original paper's model conditions.
