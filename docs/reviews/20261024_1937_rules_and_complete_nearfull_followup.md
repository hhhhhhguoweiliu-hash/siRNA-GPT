## 104→65与旧104→9，到底改了什么

原104条来自同一份siDirect 2.0输出。原请求中的Ui-Tei功能规则和21.5°C的双链seed Tm筛选设置沿用；没有今天重新改变这些原始设计条件，也没有重新请求siDirect再拼成同一批。原输出有一条打印Tm=21.5的一位小数边界，仍按协议保留标记，不从打印精度推断内部值。

从这104条继续处理时：

| 条件 | 旧九条 | 本轮65条池 |
|---|---|---|
| 旧siDirect库的双链g2–g20最小非靶错配均>=2 | 决定去留 | 仍决定去留；104中排39，留65 |
| 配对核心GC30–65% | 决定去留 | 全池阶段只记数值/官方警告，不直接删行 |
| 任一核心连续>=4个同一碱基 | 决定去留 | 不继续用这条项目额外限制直接删行 |
| 必须匹配固定全部20条参考 | 决定去留 | 记录具体覆盖和未覆盖编号；不以20/20决定全池去留 |

因此65是保留用于完整报告和后续核查的候选池，不是65条都适合实验。旧九条包含在其中。

必须进一步区分后续小试讨论名单：现有脚本只在完成检查的编码区小组里，要求OligoFormer官方序列标记0、无已映射非靶/未知映射的0或1错配长片段命中，再按官方分数取非重叠靶区。因此GC条件没有“彻底不用”：它没有在65条入池时删行，但官方标记0仍会影响小组内建议。这是两阶段处理，不能混为“65条都通过全部限制”。

## 依据能支持到什么程度

- 双链g2–g20至少2个非靶错配是siDirect 2.0官方帮助明确列出的默认条件；原104条未开隐藏特异性低候选，因此仍需读这个字段落实。原数据库准确版本未知，这项不能替代本地固定参考复核，更不是不脱靶保证。
- **纠正此前过宽的表述：GC30–65%确实有OligoFormer官方代码出处。** 固定infer.py的func_filter将范围外序列标1；其他标记包括连续5个同一碱基、连续6个G/C组成的片段和回文检查。不能继续笼统说这个GC范围没有工具依据。准确结论是：有官方实现出处，但并未证明“本项目把这些规则拼在一起”就是经过独立验证的最优VEGFA筛选方案。
- 旧“所有碱基连续4位都删除”与OligoFormer“连续5位”的定义不同。siDirect选项又区分化学合成siRNA的连续G/C与pol III表达shRNA的连续A/T，后者涉及提前转录终止，不能直接照搬给化学合成RNA。
- 全20参考覆盖是实验目标选择，不是通用效力/安全标准。不能假定参考里所有转录本都应抑制，也不能因目标范围没定就把14/20解释为70%敲低。
- 只给编码区小组作暂定提议是本轮项目范围选择，不是官方工具宣称非编码区候选无效。多工具一致与特异性线索也不替代实验验证。

## 所谓四种查询，就是两条链×两段相邻窗口

原设计每条链21位，其中第1–19位是本项目已核实的配对核心。当前输入文件逐条保存了以下四个19位窗口：

1. guide（引导链）第1–19位：与本项目配对核心/模型输入对应，作补充一致性核对。
2. guide第2–20位：与siDirect官方近全长检查定义对应。
3. passenger（另一条链）第1–19位。
4. passenger第2–20位。

每次将对应窗口的反向互补作为目标模式，在同一固定转录本参考中用Biostrings查找允许0、1、2错配、无插入缺失的命中。两窗口重叠18位，不是四种独立算法、四个预测模型或四次实验；不能说“四项独立证据都一致所以可靠性翻四倍”。检查passenger的依据是它也可能参与RNA干扰；官方siDirect直接支持的是双链第2–20位。额外检查第1–19位是本项目工程/序列核对，不能冒称文献规定必须四次。
