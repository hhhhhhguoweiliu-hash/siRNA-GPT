## 六项接口的依据与边界

| 接口 | 实际用途 | 科学定位 |
|---|---|---|
| inspect_candidates | 候选字段、长度、配对核心和支持范围校验 | 程序输入检查，不是算法预测；来源标签不等于来源已认证 |
| verify_target | 核心反向互补序列在固定VEGFA参考上的匹配 | 可复算序列核对，不等于实验沉默或完整参考覆盖 |
| score_candidates | OligoFormer效力模型输出 | 官方模型的序列效力证据；当前云端导入旧输出，不是ARPE-19专属模型 |
| match_seed | SeedMatchR得到的guide mer7m8匹配统计 | 仅潜在seed互补证据，不是全方位或实测脱靶 |
| query_expression | 匹配基因与自有基线TPM关联 | 描述性背景注释，不进入分数、不改变排序 |
| compile_report | 整合来源、提示、既定规则和结果 | 报告与透明工作规则，不是新预测模型或已验证最优筛选法 |

这六项是六个工作步骤，只有两项依托外部科学软件；其他为核对、关联和报告。范围适合小型辅助原型，但“工具选择有依据”不等于“本系统效能已被证明”。效率、准确性、异常处理及可追溯性要用真实任务对照说明；不预设Agent获胜。当前SeedMatchR历史版本仍按1.1.1追溯，不把现行2.0文档或升级结果混入旧记录。OligoFormer适配差异也须明确。

科学原始依据：OligoFormer，Bioinformatics 2024，doi:10.1093/bioinformatics/btae577；SeedMatchR，Bioinformatics 2024，doi:10.1093/bioinformatics/btae011。当前完整组成以core.py、seed_worker.R和来源记录为准；论文不能说已运行了原工具所有脱靶、毒性或RNA-seq扰动效应模块。
