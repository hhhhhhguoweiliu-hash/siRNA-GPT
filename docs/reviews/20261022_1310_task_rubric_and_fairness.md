## 本次必须指出的问题

1. **两模型组实际看见的原始输入不一致。** [运行时evaluate.py](https://github.com/hhhhhhguoweiliu-hash/siRNA-GPT/blob/e53bacba981a9082fad4df57c600eb93de159dc8/evaluate.py)给普通模型完整 `inputs`；[conversation.py](https://github.com/hhhhhhguoweiliu-hash/siRNA-GPT/blob/e53bacba981a9082fad4df57c600eb93de159dc8/conversation.py)的 `propose()`只传候选数量，没有候选行。PR最新代码此处仍相同。Agent A028/A037（AAA）及A024/A036/A040（21nt）因此声称没给序列；不能把这些idle状态计成正确澄清或归因于模型能力差。A048是计划必须含1–6工具的格式失败，应留在系统失败记录中，不按外部网络错误排除。
2. **工具正确不保证回答正确。** A043把728/1333叫作“可映射seed基因”，工具值实际是726/1330。保留原回答，以复核批注纠正，下一批固定输出字段名称与单位。普通模型也有可核查错误：A020/A039给出的所谓19nt格式示例实际只有17个A。两组用同一事实标准，不能只审某组。
3. **输出和评审材料尚不对等。** Agent有“通常两到四句话”的风格提示，普通模型没有相同提示，普通模型正常回答明显更长；6次不完整响应原因又未留全，不能直接认定全由1800上限造成。[现有评审表](https://github.com/hhhhhhguoweiliu-hash/siRNA-GPT/blob/c6970b8ba0ae437716d7a82e89bf89f53d5ce141/research/2026-10-20_takeover/three_arm/for_review/blind_answers.tsv)只附一句需求，没有结构化候选输入；评审看不到AAA/21nt已上传，也无法判断哪些数值原先就在输入里。新批需统一简短最终输出结构，并给评审完整题目输入及匿名证据。

## 三组怎样比较才公平

| 要保持一致 | 具体做法与比较边界 |
|---|---|
| 同一原始信息 | 三组同题、同候选行、同状态/数量/目标、同参考/数据版本。规划器须能看到实际序列、字段及已有标注。输入已有20/20匹配字段应向各组公开；其转述不能算新独立比对能力 |
| 清楚说明能力差异 | 普通模型没有科学工具；固定流程和Agent有相同工具与历史数据。固定流程由人预选preset（执行路径），不能据此比较自由语言规划。当前三组比较的是整套系统配置，不能将优势全部归因于Agent自主推理 |
| 同等最终回答要求 | 共用“判定—关键结果表—证据—限制/下一步”简短格式；固定流程可用确定性模板呈现，不能额外调用模型润色。改变展示不改原始回答，不删错误。无工具组可明确缺项，不强迫猜数 |
| 模型与资源可解释 | 两模型组同版本、思考设置、每次请求输出上限、重试和超时规则，运行前记录实际生效参数。Agent多轮、普通模型单轮应写清，总预算并不相等；报告实际调用与完整性，不宣称同成本。规划用量缺失时总量未知，只报已知小计 |
| 不挑样本、不按调用数打分 | 所有54计划单元保留。正常、仅核对、异常三类分开报；3次先按题整理，不当18道独立题。异常任务正确停止、仅核对任务只用2工具都可满足要求，多调工具没有额外分 |
| 评分独立且有完整上下文 | 领域人员事先审核任务/标准，最好两人独立评分，再处理分歧。给他们完整题目输入、允许资源说明、匿名回答/证据和标准，不给组别密钥；统一版式不改写答案。风格可能暴露组别，需如实说明 |

固定流程与Agent是工具条件较接近的对照；普通模型与Agent反映完整配置差异。若以后要单独证明“同证据下解释更好”或“自主规划更好”，需另设同证据/同任务信息的评价，不把它加成本批的新前置条件。

## 如何记分和处理失败

继续沿用原有四项0–2分，分项报告，不临时融合成“科学准确率”：事实准确、证据支持、需求完成、边界处理。2为充分满足该题条件，1为部分满足/有明确缺漏，0为明确错误/未达到；评审写出所据输入、工具字段或回答句子。

- **事实准确**看序列、坐标、数字、状态和术语含义；“数字抄对但名称叫错”也算问题。
- **证据支持**允许引用用户已给记录，不唯工具数量论。没有数据时如实说未知，与无依据编数分开。
- **需求完成**按上面的逐题要求，不能因正常题诚实承认做不了而算完成；异常题准确指出问题并停止可满足要求。
- **边界处理**看是否守住靶点、链方向、历史/新计算和实验结论等限制。伪称运行工具不得因其它文字流畅获得满项。

分两张表：第一张保留全部54条的可用性/完成情况和原因；第二张呈现可读回答的独立质量分及各题有效数量。网络失败或没有可读的输出时，质量缺失记不可评分，不能填科学错误0分；同时在第一张表保留为未交付。截断是输出/协议失败，原因未知时不能全当不可控外部故障删掉。A048程序/规划失败也必须计入系统表现，不能用“不可评分”抹去。

按题并列三组结果与3次波动，不按回复长短、工具数量、状态COMPLETE或自动哈希校验给质量分。当前缺氧题普通模型无完整响应，不算全六题总质量分，不挑成功重复作论文优越性或显著性图。
