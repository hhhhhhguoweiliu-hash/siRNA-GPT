# 科研真实性、完整性与论文图准入

用户2026-10-20的明确长期要求：结果、数据、图必须真实，尤其论文内容不能造假；能做就做，不能做如实说明；完整预定流程和数据不足时，不得选取部分成功数据出图并冒充完成的研究。

## 交付门槛

1. 每个数值和数据点可追溯到原始文件、真实运行或清楚标注的历史输出。区分原始测量、计算结果、模型解释、示意图及未完成事项。
2. 图必须使用与其结论对应的完整预定数据；保留全部计划单元、失败与缺失。不替换失败，不挑成功重复，不用局部配对冒充完整三组评价。
3. 文件哈希/CRC证明文件一致性，不单独证明真实实验过程、上游模型执行或LLM解释正确。语义结论逐条核对；不把模型总结直接当科研结果。
4. 运行状态、工具数量与软件检查数不当科学准确率或科研样本量。所有质量分数必须来自真实评分；所有湿实验必须来自真实测量。
5. 排障图只能承担工程诊断；未达到质量评价门槛，不进入论文质量比较结果。示意图和完整单案例可以承担相应有限用途，不能代替独立评价或湿实验。
6. 英文论文图内文字和正式图注为英文。使用真实Arial；粗体小写分图标签，必要的标题与表头粗体，常规文本统一字重；实际检查PDF嵌入字体、SVG可编辑文字、字形覆盖和排版。禁止静默回退字体。
