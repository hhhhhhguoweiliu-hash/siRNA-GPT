# 课题全貌与最小毕业主线

## 建议定位

缺氧RPE/VEGFA siRNA候选核对与筛选辅助Agent构建及可用性评价。CNV是应用背景和动机，不把ARPE-19缺氧模型等同于CNV病灶或动物疗效。

用户目标是先做出小而完整的Agent、跑通流程、产出可靠结果用于毕业。不要为追求原文全部复杂度，提前扩展动物/类器官、大规模新RNA-seq、专用模型训练或全新脱靶算法。

## 系统要解决什么

研究者提供目标、细胞场景、来源明确的候选和表达数据。Agent理解需要做哪些核对，调用已发表工具/既有结果，发现不支持或有歧义时澄清，关联本实验背景，交付候选证据表、可解释的优先复核名单和原始记录。它的价值需要通过需求理解、错误处理、证据可靠性、任务完成与效率评价，不能仅凭“接了LLM”宣称创新成立。

## 两条证据链

1. 计算评价：普通LLM、固定工具流程、Agent；同模型/工具/数据版本与相同任务条件，正常与异常任务分开，保存所有运行，必要时重复，独立评审按预定标准判分。这条链承担系统价值评价。
2. 小规模湿实验：使用用户实际文献siRNA，确认需求到候选的可执行性。提前冻结候选及理由；如实报告结果。已知siRNA有效不单独证明Agent优越，因此这条链定位为端到端可用性案例。

## 当前三个科学证据层

- 序列层：方向/19nt配对核心/参考转录本核对，OligoFormer序列效力证据。
- 潜在seed匹配层：SeedMatchR官方匹配及已有近似互补记录，不能当全面毒性预测。
- 细胞背景层：自有常氧/缺氧TPM与匹配基因关联，分别报告两状态、未映射和阈值敏感性。当前不改变排名，不能宣称已经预测状态特异敲低率。

若后续要让表达参与正式排序，先提出透明方案并独立验证；不临时把TPM乘进效力分数，或把匹配基因数直接说成毒性概率。

## 参考文献迁移边界

参考CRISPR-GPT（doi:10.1038/s41551-025-01463-z）的交互模式、受控规划、状态机执行、工具协作、来源溯源和分层评价。作者完整系统还含专家知识与专用Llama3微调；本项目当前单豆包API、多阶段控制器和关键词资料检索是简化迁移，不是等价复现。

原文构建288任务bench、专家评价并有实际湿实验。本项目尚无同等规模/完成度。固定脚本组是本课题为区分“工具贡献”和“LLM调度贡献”而增加的设计，不包装成原文完全相同的对照。

## 最小完成标准

1. 用户真实候选和背景数据能够被核对并处理，输入错误有可理解反馈。
2. 需要的官方工具在可访问计算环境中运行，或明确标注已验证结果导入；不混淆二者。
3. 至少完成合规的小规模三组运行，之后用经独立审核的测试集评价，不能只有截图/成功案例。
4. 报告、版本、工具输入输出和失败证据可追溯，能导出并重现核心表图。
5. 用户完成既定小规模实验，科学结论与模型和实验范围相符，导师认可最终论文定位。

原有HCR/双靶点递送可以作为背景或后续扩展，不强制并入此版Agent主线。当前不自动扩大到siHIF筛选。
